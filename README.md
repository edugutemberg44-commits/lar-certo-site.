# Lar Certo — hero inspirado no Zênite

Implementação da primeira dobra com cidade flutuante, camadas de nuvens, parallax, animação de entrada simplificada e transição para um bloco de fechamento. O PROMPT.md e CLAUDE.md originais estão preservados.

## Executar

`npm install` e `npm run dev`. O Vite serve em http://localhost:5190.

## Observações

A referência visual da cidade foi criada para esta adaptação. A implementação é uma aproximação funcional: ainda não reproduz fielmente a sequência GSAP letra a letra nem todos os recortes/posicionamentos do projeto Zênite. O endereço de contato é ilustrativo e deve ser substituído antes da publicação. Não publicar sem verificar responsividade, acessibilidade e direitos dos elementos usados.
